# Proyecto inicial

Generador de boletas de pago a partir de planillas Excel.

- Carga de archivo Excel (.xlsx)
- Seleccion de hoja con busqueda fuzzy
- Parsing de planilla: nombre, puesto, salario, bonificaciones, descuentos
- Generacion de boletas en formato visual
- Exportacion a PDF (individual y en lote via ZIP)
- Impresion directa desde el navegador
